1. Biến (Variables) - Nơi Lưu Trữ Ký Ức

Trong JS, bạn tạo ra các "thùng chứa" để lưu thông tin. Có 3 từ khóa quan trọng:

let

Dùng cho giá trị có thể thay đổi (ví dụ: điểm số, số lượng giỏ hàng).

const

Dùng cho giá trị cố định (ví dụ: ngày sinh, tên người dùng, số Pi).

const user = "Văn Phúc"; let score = 100; score = score + 10; // Cập nhật điểm thành 110

2. Thao tác DOM (Cầu nối HTML - JS)

Đây là cách JS "chạm" vào HTML để đổi màu, đổi chữ hoặc ẩn hiện phần tử.

Quy trình 3 bước thần thánh:

  1. Tìm: document.querySelector()
  2. Lắng nghe: .addEventListener("click", ...)
  3. Hành động: Thay đổi CSS hoặc Nội dung.
// Ví dụ: Bấm nút để đổi màu nền const button = document.querySelector(".btn-magic"); button.addEventListener("click", () => { document.body.style.backgroundColor = "skyblue"; });

3. Câu lệnh Điều kiện & Vòng lặp

Giúp máy tính đưa ra quyết định dựa trên dữ liệu đầu vào.

> let age = 18;
> if (age >= 18) {
    console.log("Bạn đã đủ tuổi xem phim này!");
  }
"Bạn đã đủ tuổi xem phim này!"

4. JavaScript Event Loop (Phía sau hậu trường)

JavaScript xử lý hàng nghìn yêu cầu cùng lúc nhờ cơ chế hàng đợi bất đồng bộ.

Stack

Nơi các lệnh đang chạy ngay lập tức.

Queue

Nơi các sự kiện (Click, Timer) chờ được xử lý.
