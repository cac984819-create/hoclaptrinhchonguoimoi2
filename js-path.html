JavaScript: Bộ Não Của Trang Web

Giúp trang web biết suy nghĩ, tính toán và trò chuyện với người dùng.

1. JavaScript là gì?

JavaScript (JS) là ngôn ngữ lập trình. Nó cho phép bạn thực hiện những việc như: Hiện thông báo khi bấm nút, đổi màu nền khi cuộn chuột, hoặc kiểm tra xem mật khẩu có đủ mạnh không.

Biến (Variables) - Nơi cất giữ dữ liệu

Hãy tưởng tượng bạn có một chiếc hộp tên là tenCuaToi và bạn bỏ chữ "Gemini" vào đó.

let tenCuaToi = "Gemini"; alert("Chào mừng " + tenCuaToi); // Hiện thông báo: Chào mừng Gemini

2. DOM - Cầu nối với HTML

Để JS có thể điều khiển HTML, nó sử dụng một "bản đồ" gọi là DOM.

1. JS tìm thẻ HTML (ví dụ: cái nút).
2. JS lắng nghe hành động (ví dụ: người dùng click).
3. JS thực hiện lệnh (ví dụ: đổi màu trang web).

3. Event Loop - Cách JS làm việc

JavaScript rất bận rộn. Nó có một "vòng lặp sự kiện" để đảm bảo mọi lệnh được thực hiện đúng thứ tự mà không bị treo máy.
