CSS: Biến Bản Vẽ Thành Tuyệt Tác

Nếu HTML là xương cốt, CSS chính là làn da, mái tóc và bộ quần áo lộng lẫy của trang web.

1. Cách cài đặt CSS

Có 3 cách phổ biến để nhúng CSS vào trang HTML của bạn:

  • External: Liên kết file .css bên ngoài (Dùng thẻ <link>).
  • Internal: Viết trực tiếp vào file HTML (Dùng thẻ <style>).
  • Inline: Viết trực tiếp vào thuộc tính style của thẻ HTML.
/* Ví dụ External CSS */ <link rel="stylesheet" href="style.css"> /* Ví dụ Internal CSS */ <style> h1 { color: red; } </style>

2. CSS là gì?

CSS giúp bạn chọn một thẻ HTML và ra lệnh cho nó phải trông như thế nào. Cấu trúc gồm: Selector (Chọn ai) và Declaration (Lệnh gì).

h1 { color: blue; /* Màu chữ xanh */ font-size: 24px; /* Cỡ chữ 24 pixel */ text-align: center; /* Căn giữa */ }

3. Bí mật của "Chiếc hộp" (Box Model)

Mọi thứ trên web đều là những chiếc hộp hình chữ nhật lồng nhau. Hiểu được điều này là bạn đã nắm 50% sức mạnh CSS.

  • Content: Nội dung (Chữ hoặc ảnh).
  • Padding: Khoảng đệm (Lớp bông bên trong hộp).
  • Border: Vỏ hộp (Đường viền).
  • Margin: Khoảng cách giữa các hộp (Để chúng không dính vào nhau).

4. Cách sắp xếp (Flexbox)

Làm sao để đưa các nút bấm nằm ngang hàng? Ta dùng "phép thuật" Flexbox.

.container { display: flex; justify-content: space-between; /* Đẩy các phần tử ra xa nhau */ }
