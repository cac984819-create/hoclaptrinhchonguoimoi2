CSS: Biến Bản Vẽ Thành Tuyệt Tác

Nếu HTML là xương cốt, CSS chính là làn da và bộ quần áo lộng lẫy của trang web.

0. Cách cài đặt CSS

Để trình duyệt hiểu được phong cách bạn muốn, hãy sử dụng một trong ba cách sau:

  • External: Liên kết file .css bên ngoài (Khuyên dùng).
  • Internal: Viết trong thẻ <style> ở đầu trang.
  • Inline: Viết trực tiếp vào thẻ HTML qua thuộc tính style.
<!-- Cách chuẩn nhất: External --> <link rel="stylesheet" href="style.css">

1. Selector & Declaration

CSS hoạt động theo cơ chế: Chọn một đối tượng và Ra lệnh thay đổi.

selector { property: value; /* Một lệnh thay đổi */ } h1 { color: #2965f1; /* Đổi màu chữ */ font-size: 32px; /* Đổi kích thước */ }

2. Bí mật của "Chiếc hộp" (Box Model)

Mọi thành phần trên web đều được trình duyệt xem là một chiếc hộp. Việc hiểu cách các lớp bao bọc nhau là chìa khóa để làm chủ bố cục.

BORDER
PADDING
CONTENT

Ghi nhớ nhanh:

  • Content: Chứa văn bản/hình ảnh.
  • Padding: Khoảng trống bên trong (giữa ruột và vỏ).
  • Border: Đường viền của hộp.
  • Margin: Khoảng cách bên ngoài để đẩy các hộp khác ra xa.

💡 Pro Tip: Luôn dùng box-sizing: border-box; để padding không làm tăng chiều rộng thực tế của hộp.

3. Bố cục hiện đại với Flexbox

Flexbox giúp bạn dàn hàng các phần tử và căn giữa chúng một cách cực kỳ dễ dàng, thay thế hoàn toàn các phương pháp cũ lỗi thời.

Các lệnh Flexbox phổ biến nhất:

display: flex; /* Kích hoạt chế độ Flex */ justify-content: center; /* Căn giữa theo chiều ngang */ align-items: center; /* Căn giữa theo chiều dọc */ gap: 20px; /* Khoảng cách giữa các phần tử */

Ứng dụng: Tạo Navbar trong 30 giây

.nav { display: flex; justify-content: space-between; /* Đẩy Logo sang trái, Menu sang phải */ align-items: center; }
